# 空间工作台接入路线图（占位阶段）

本文件用于说明当前 `/workspace/**` 占位页的后续接入方向与与既有 `/space/**` 的过渡关系。

## 1. /workspace/home 计划接入能力

1. 个人视角概览
2. 最近访问空间列表
3. 待办/通知入口（仅展示，不做裁决）
4. 常用模块快捷入口

## 2. /workspace/spaces/:id/home 计划接入能力

1. 空间概览卡片（基础信息、成员、状态）
2. 业务模块入口集合（后续再接入）
3. 与空间内工作项的跳转入口（仅跳转，不重构）

## 3. 与现有 /space/** 的过渡关系

1. 当前阶段：/workspace 作为业务入口壳子，/space/** 仍为现有业务配置与工作项主入口
2. 后续阶段：逐步将空间内业务入口迁移到 /workspace/spaces/:id/home，再从该入口分发到原 /space/** 路由
3. 迁移节奏：先入口统一、再功能迁移，不触碰泳道图与流程图相关页面

## 4. 后续迁移优先级建议

1. 先迁空间概览与导航入口
2. 再迁轻量业务列表页（如工作项列表）
3. 最后评估是否迁移配置页（泳道图、流程图相关保持不动）

## 5. 当前明确不动的能力

- 泳道图相关页面与组件
- 流程图/节点布局/连线路由模块
- Flowable 执行主链路
